# PSV Organisationsmodell

> Organisationsentwicklung des Pferdesportvereins Ulm/Neu-Ulm e.V.

## Ziel des Projekts

Dieses Repository dokumentiert die Entwicklung des Organisationsmodells des Pferdesportvereins Ulm/Neu-Ulm e.V.

Ziel ist es, eine Organisationsstruktur zu schaffen, die

- Verantwortung klar zuordnet,
- fachliche Kompetenz sinnvoll bündelt,
- den Vorstand entlastet,
- Transparenz schafft und
- langfristig mit dem Verein mitwachsen kann.

Das Organisationsmodell besteht aus mehreren aufeinander aufbauenden Dokumenten.

## Dokumentenstruktur

```
Satzung
      │
      ▼
Rahmenordnung
      │
      ▼
Abteilungsordnungen
      │
      ▼
Richtlinien
      │
      ▼
Werkzeugkasten
```

Das Organisationshandbuch erläutert ausschließlich die Organisationsphilosophie des Vereins.

Verbindliche Regelungen ergeben sich ausschließlich aus

- der Satzung,
- der Rahmenordnung,
- den Abteilungsordnungen sowie
- den hierzu erlassenen Richtlinien.

## Organisationsphilosophie

Das Organisationsmodell verfolgt einen einfachen Grundsatz:

> **Verantwortung folgt Kompetenz.**

Fachabteilungen werden nicht gegründet, weil Aufgaben vorhanden sind.

Sie werden dort eingerichtet, wo dadurch Verantwortung besser wahrgenommen werden kann und ein nachhaltiger Mehrwert für den Gesamtverein entsteht.

Alle übrigen Aufgaben verbleiben bewusst beim Gesamtvorstand.

Dadurch bleibt die Vereinsorganisation schlank, flexibel und entwicklungsfähig.
